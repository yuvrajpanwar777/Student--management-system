# Student Management System

## Project Description

This is a Python-based Student Management System developed as part of the Python Essentials Evaluated Course Project.

## Features

* Add student records
* View student records
* Search students
* Update student information
* Delete student records
* Simple menu-driven interface

## Technologies Used

* Python 3
* Functions
* Lists and Dictionaries
* File Handling
* Exception Handling

## How to Run

1. Install Python 3.
2. Download the project file.
3. Open the terminal in the project folder.
4. Run the command:

```bash
python student_management_system.py
```
